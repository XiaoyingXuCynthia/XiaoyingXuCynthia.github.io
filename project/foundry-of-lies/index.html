PROJECT DESCRIPTION

Based on Hangzhou Qianchao Cement Factory, the project began as an abandoned-factory environment created in Unreal Engine 5. It was later expanded into a third-person shooter through narrative and video scripting, environment iteration, Blueprint systems, and UI interaction, transforming a static scene into a complete space for exploration and combat.
